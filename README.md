# 🎒 小書包的校園大冒險 —— 小一新鮮人闖關挑戰

> 一款用 **p5.js** 製作的多媒體闖關測驗遊戲，幫助即將上小學的孩子認識校園生活規則。

---

## 一、作品簡介

即將升上小一的孩子，常常對「上課鐘、下課鐘、舉手發言、排隊、午休」這些新規則感到陌生又緊張。

本作品設計了一位吉祥物 **「小書包」**，以說故事的方式帶領孩子「走一趟校園」：從早上進校門開始，經過教室、走廊、遊樂場、午餐，一路到放學回家。每到一個地點就是一個關卡，答對題目可以收集星星，過關還能在「小一新生護照」上蓋印章。

讓孩子在玩遊戲的過程中，**先在心裡預習一次上學的一整天**。

---

## 二、設計理念與創意

| 一般測驗 | 本作品的闖關設計 |
|---|---|
| 題目一題接一題，沒有情境 | 依照「上學的一天」順序安排 6 個關卡，有故事感 |
| 只顯示分數 | 收集星星 ⭐、蓋過關印章、最後拿到「新生護照」 |
| 答錯就扣分 | 答錯一樣能前進，並由小書包溫柔解說正確做法，不讓孩子有挫折感 |
| 靜態圖片 | 每題都有即時繪製的小動畫，介面中的角色會眨眼、揮手、走路 |
| 只有文字 | 鐘聲題要「用耳朵聽」來作答，加入聲音互動 |

### 吉祥物：小書包 🎒
- 全部用 p5.js 的圖形（矩形、圓弧、橢圓）畫出，沒有使用任何圖片檔
- 會上下輕輕浮動、自動眨眼
- 有三種表情：😊 開心（happy）、🙌 歡呼揮手（cheer）、😮 驚訝（oops）

## 三、遊戲流程

```mermaid
graph LR
  A[標題畫面] --> B[小書包說故事]
  B --> C[校園地圖]
  C --> D[關卡介紹]
  D --> E[答題]
  E --> F[解說]
  F -->|還有題目| E
  F -->|本關結束| G[過關蓋章]
  G -->|還有關卡| C
  G -->|6 關全破| H[小一新生護照]
  H -->|再玩一次| C
```

1. **標題畫面**：遊戲名稱、小書包與學校建築
2. **開場故事**：小書包用「打字機效果」對話框介紹遊戲，可點擊加速或跳過
3. **校園地圖**：6 個關卡沿著小路排列，已過關的會打勾並顯示星星，未解鎖的會上鎖
4. **關卡介紹**：彈出卡片，小書包說明這一關的場景
5. **答題 → 解說**：每關 2 題，答完立即看到對錯與解說
6. **過關蓋章**：印章「蓋」下來的動畫、彩帶、星星結算
7. **走向下一站**：小書包在地圖上一跳一跳走到下一個關卡
8. **新生護照**：顯示 6 個印章、總星星數與稱號

## 四、關卡與題庫

共 **6 關、18 題**，每關從題庫抽 2 題，每次遊玩共 12 題（滿分 12 顆星）。

| 關卡 | 地點 | 題目（★ 為每次必出） |
|---|---|---|
| 1 | 🏫 校門口 | 向老師問好、走斑馬線過馬路、和爸媽說再見 |
| 2 | 📚 教室 | ★ 上課鐘聲（是非題）、舉手回答、上課想上廁所、找不到橡皮擦 |
| 3 | 🚸 下課走廊 | ★ 下課鐘聲（是非題）、走廊慢慢走、撞到同學、下課先收桌面 |
| 4 | ⚽ 遊樂場 | 聽到鐘聲回教室、排隊盪鞦韆、跌倒受傷 |
| 5 | 🍱 午餐時間 | 飯前洗手、不喜歡的青菜、廚餘與餐具 |
| 6 | 🌙 午休放學 | 午休安靜、聯絡簿、陌生人說要接你 |

### 稱號
| 星星數 | 稱號 |
|---|---|
| 12 | 校園小達人 |
| 9～11 | 準備好囉！ |
| 6～8 | 小小新鮮人 |
| 0～5 | 見習新生 |

## 五、多媒體元素

| 類型 | 做法 |
|---|---|
| 🎨 動畫 | 18 種情境小動畫（`drawScenarioImage`）用 `frameCount` 搭配 `sin()` 做出擺動、跳動、上升效果 |
| 🎒 角色 | 小書包角色（`drawMascot`）會浮動、眨眼、揮手 |
| 🗺️ 地圖 | 用 `curveVertex` 畫出彎曲小路，角色移動用緩動函數＋跳躍 |
| 🔔 音效 | 使用 **Web Audio API** 即時合成，不需要任何音檔：上課鐘、下課鐘、答對、答錯、點擊、走路、蓋章、勝利音樂 |
| 🎉 特效 | 彩帶粒子、旋轉光芒、印章縮放動畫、打字機文字 |

## 六、操作方式

- 全程使用 **滑鼠點擊**（手機、平板可用手指點）
- 開場故事：點畫面任一處繼續，或按右上角「跳過故事」
- 鐘聲題會自動播放鐘聲，也可以按「🔊 再聽一次鐘聲」
- 畫面會自動縮放，適合各種螢幕大小

## 七、程式架構（sketch.js）

| 區塊 | 內容 |
|---|---|
| 0. 畫布設定 | 以 960×640 設計，再等比例縮放、置中 |
| 1. 題庫 | `QUESTION_BANK`，18 題 |
| 2. 關卡設定 | `LEVELS`：名稱、圖示、顏色、地圖座標、必出題與抽題題庫 |
| 3. 遊戲狀態 | `state` 狀態機：TITLE → STORY → MAP → LEVEL_INTRO → QUESTION → EXPLANATION → LEVEL_CLEAR → RESULT |
| 4. 音效 | `tone()` 合成單音，`playSound()` 組合成各種音效 |
| 5. 小工具 | 洗牌、中文換行、按鈕、星星、對話泡泡 |
| 6. 角色與場景 | 小書包、雲朵、學校、樹、印章、彩帶 |
| 7. 情境動畫 | 每題對應的動畫小圖 |
| 8. 生命週期 | `setup()`、`draw()` |
| 9. 各畫面 | 每個狀態的繪製函式 |
| 10. 事件 | `mousePressed()` 統一處理點擊 |

### 技術重點
- **按鈕系統**：每一幀畫按鈕時同時登記點擊範圍，`mousePressed()` 只需檢查清單，不用重複計算座標
- **隨機出題**：每關有必出題＋從題庫隨機抽題，選項順序也會打亂，每次玩都不一樣
- **等比例縮放**：所有座標以 960×640 設計，`draw()` 內用 `translate()`＋`scale()` 適應視窗

## 九、執行方式

1. 用 VS Code 開啟 `school-adventure` 資料夾
2. 安裝擴充套件 **Live Server**
3. 在 `index.html` 上按右鍵 →「Open with Live Server」
4. 瀏覽器開啟後即可遊玩（需連網以載入 p5.js 與字型）
